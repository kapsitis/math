# <lo-sample/> EE.PK.2021TEST.8.1

Вычислить:
$$\frac{20+20\cdot20-21\cdot21+21}{20^2+21^2}=$$

<small>

* answer:$0$
* questionType:ShortAnswer

</small>

## Решение

$$\frac{20+20\cdot20-21\cdot21+21}{20^2+21^2}=\frac{20(1+20)-21(21-1)}{20^2+21^2}=\frac{20\cdot21-21\cdot20}{20^2+21^2}=0.$$


# <lo-sample/> EE.PK.2021TEST.8.2

Найти число, которое лежит на числовой оси между числами $\frac{1}{3}$ и $\frac{1}{2}$, и которое в два раза ближе к числу $\frac{1}{3}$, чем к числу $\frac{1}{2}$.

<small>

* answer:$\frac{7}{18}$
* questionType:ShortAnswer

</small>

## Решение

Из описания числа получаем уравнение $\frac{1}{2}-x=2\left(x-\frac{1}{3}\right)$, при упрощении которого получаем $3x=\frac{1}{2}+\frac{2}{3}=\frac{7}{6}$, откуда $x=\frac{7}{18}$.

<small>

* answer:$-4$
* questionType:ShortAnswer

</small>

## Решение

Данное равенство $3(4b-5)-2(3a+4)=1$ упрощается до вида $12b-6a=24$, где при делении обеих частей равенства на число $-6$ получаем $a-2b=-4$.


# <lo-sample/> EE.PK.2021TEST.8.4

Найти наименьшее простое число, равное сумме трёх различных простых чисел.

<small>

* answer:$19$
* questionType:ShortAnswer

</small>

## Решение

Сумма трёх различных простых чисел, очевидно, больше единственного чётного простого числа 2. Значит, эта сумма нечётная. Следовательно, все три слагаемых нечётные, так как при сложении одного чётного и двух нечётных простых чисел получилось бы чётное число. Три наименьших нечётных простых числа 3, 5, 7 дают сумму 15, которая не является простым числом. Следующая по величине сумма получится, если вместо слагаемого 7 взять следующее простое число 11. Теперь сумма равна 19, что является простым числом.


# <lo-sample/> EE.PK.2021TEST.8.5

Цены двух футболок отличаются на 20 евро. Их средняя цена равна 21 евро. Сколько стоит более дешёвая из этих футболок?

<small>

* answer:$11$ евро
* questionType:ShortAnswer

</small>

## Решение

Пусть цена более дешёвой футболки равна $x$ евро, тогда цена более дорогой футболки равна $x+20$ евро. Получаем уравнение $\frac{x+(x+20)}{2}=21$, откуда $x=11$.


# <lo-sample/> EE.PK.2021TEST.8.6

Какая часть всех четырёхзначных чисел, цифрами которых являются 2, 0, 2 и 1, делится на число 4?

<small>

* answer:$\frac{1}{3}$
* questionType:ShortAnswer

</small>

## Решение

Для выбора места цифры 0 в четырёхзначном числе есть 3 возможности, так как число не может начинаться с нуля. После этого для выбора места цифры 1 остаётся ещё 3 возможности. Тем самым четырёхзначное число, образованное из данных цифр, определено, так как на оставшихся местах должны находиться цифры 2. Всего из данных цифр можно составить $3\cdot3$, то есть 9 различных четырёхзначных чисел. Чтобы число делилось на 4, число, образованное двумя последними цифрами, должно делиться на 4. Такие двузначные числа, образованные из данных цифр, — это 12 и 20. В первом случае порядок двух первых цифр определён, так как число не может начинаться с нуля. Во втором случае для выбора порядка двух первых цифр есть 2 возможности. Всего получаем 3 подходящих четырёхзначных числа. Их доля среди всех составляемых четырёхзначных чисел равна $\frac{3}{9}$, то есть $\frac{1}{3}$.

# <lo-sample/> EE.PK.2021TEST.8.8

Одна из сторон треугольника поделена на отрезки, длины которых 1 см, 2 см и 3 см. Найти площадь закрашенного в тёмный цвет треугольника, если сумма площадей незакрашенных частей равна $7\ \mathrm{см}^2$.

![](EE.PK.2021TEST.8.8.png)

<small>

* answer:$3,5\ \mathrm{см}^2$
* questionType:ShortAnswer

</small>

## Решение

Сумма длин оснований двух незакрашенных треугольников равна 4 см, то есть в 2 раза больше длины основания закрашенного треугольника, равной 2 см. Так как у всех трёх треугольников общая высота, то и сумма площадей незакрашенных треугольников в 2 раза больше площади закрашенного треугольника. Следовательно, площадь закрашенного треугольника равна половине суммы площадей незакрашенных частей, то есть $3,5\ \mathrm{см}^2$.


# <lo-sample/> EE.PK.2021TEST.8.9

Фигура составлена из квадрата с длиной стороны 1 см и из четверти круга, радиус которого 1 см. Найти точное значение площади закрашенной части, если величина угла $ABC$ равна $60^\circ$.

![](EE.PK.2021TEST.8.9.png)

<small>

* answer:$\frac{5}{24}\pi\ \mathrm{см}^2$
* questionType:ShortAnswer

</small>

## Решение

Угол $ABC$ состоит из угла между стороной и диагональю квадрата и угла незакрашенного сектора четверти круга. Угол между стороной и диагональю квадрата равен $45^\circ$. Следовательно, угол незакрашенного сектора четверти круга равен $15^\circ$. Тогда угол закрашенного сектора равен $75^\circ$. Площадь сектора равна $\frac{75^\circ}{360^\circ}\cdot\pi\cdot1^2$, то есть $\frac{5}{24}\pi$ квадратных сантиметра.
