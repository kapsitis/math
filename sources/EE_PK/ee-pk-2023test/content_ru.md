$$

<small>

* answer:$4$
* questionType:ShortAnswer

</small>

## Решение

Так как $a = 2b$, то $a + b = 2b + b = 3b$. Теперь, так как $3b = 4c$, то

$$
\frac{a + b}{c} = \frac{4c}{c} = 4.
$$

* answer:$40^\circ$
* questionType:ShortAnswer

</small>

# <lo-sample/> EE.PK.2023TEST.9.10

На рисунке показан вид сверху тела, образованного из серых (все грани серые) и белых (все грани белые) кубиков. Кубики из тела можно забирать по одному, но только тогда, когда у забираемого кубика видны хотя бы 3 его грани. Нижние грани всех кубиков лежат на одной и той же плоскости, и они не видны. Найти наименьшее количество белых кубиков, которые необходимо забрать из тела для того, чтобы можно было забрать из него все серые кубики.

![](EE.PK.2023TEST.9.10.png)

<small>

* answer:$4$
* questionType:ShortAnswer

</small>

## Решение

Если сначала забрать два угловых серых кубика, то затем можно забрать 4 белых соседних кубика удаленных кубиков. После этого можно забрать все оставшиеся серые кубики. Следовательно, достаточно удалить 4 белых кубика. Покажем, что удаления меньшего числа белых кубиков недостаточно. Рассмотрим два случая.

* Предположим, что удаляются два центральных белых кубика. Для удаления первого из них нужно удалить два соседних серых кубика, что, однако, требует удаления еще хотя бы одного белого кубика. Удаление только одного дополнительного белого кубика было бы возможно только в случае, если бы это был угловой кубик. Тогда, однако, невозможно удалить второй центральный белый кубик, не удалив еще один белый кубик.

* Предположим, что хотя бы один из двух центральных белых кубиков остается на месте. Без ограничения общности пусть это юго-восточный относительно центра кубик. У каждого из двух центральных серых кубиков из оставшихся трех белых соседних кубиков нужно удалить два. Чтобы ограничиться удалением менее чем 4 белых кубиков, один из этих белых соседних кубиков центральных серых кубиков должен быть одним и тем же. Единственный такой кубик — северо-западный центральный белый кубик. Следовательно, этот кубик нужно удалить, кроме того, один из двух белых кубиков левой нижней четверти и один из двух белых кубиков правой верхней четверти. Чтобы можно было удалить серые кубики правой нижней четверти, нужно, однако, удалить один из белых кубиков нижнего ряда и один из белых кубиков правого столбца. Всего этого вместе можно достичь удалением 3 белых кубиков только в случае, если удаляются белые кубики второго слева столбца и второй сверху строки. Но для удаления северо-западного центрального белого кубика нужно удалить хотя бы один кубик верхнего ряда или левого столбца. Следовательно, удалением менее чем 4 белых кубиков невозможно забрать все серые кубики.

*Замечание.* Различных решений с удалением 4 белых кубиков больше. Например, можно удалить угловые белые кубики, затем расположенные рядом с ними серые кубики, и после этого с каждой стороны можно удалить один из центральных белых кубиков. После этого удаляемы все оставшиеся серые кубики.
